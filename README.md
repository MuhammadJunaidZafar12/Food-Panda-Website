# FoodPanda Documentation

This directory contains the implementation-based documentation for the project.

- [PROJECT_DOCUMENTATION.md](PROJECT_DOCUMENTATION.md): complete architecture, setup, flows, relationships, security, and known gaps.
- [AUTH_DOCUMENTATION.md](AUTH_DOCUMENTATION.md): registration, login, JWT, roles, and user administration.
- [RESTAURANT_DOCUMENTATION.md](RESTAURANT_DOCUMENTATION.md): discovery, geo-filtering, owner CRUD, moderation, and restaurant data.
- [PRODUCT_DOCUMENTATION.md](PRODUCT_DOCUMENTATION.md): menu products, image uploads, owner CRUD, and cart handoff.
- [CART_DOCUMENTATION.md](CART_DOCUMENTATION.md): authenticated cart lifecycle and restaurant conflict behavior.
- [ORDER_DOCUMENTATION.md](ORDER_DOCUMENTATION.md): checkout, totals, snapshots, lifecycle, assignment, and tracking.
- [RIDER_DOCUMENTATION.md](RIDER_DOCUMENTATION.md): rider dashboard, assignments, delivery status, availability, and GPS.
- [LOCATION_DOCUMENTATION.md](LOCATION_DOCUMENTATION.md): browser GPS, destination persistence, geocoding, and radius search.
- [MAPS_DOCUMENTATION.md](MAPS_DOCUMENTATION.md): Leaflet maps, OpenStreetMap, OSRM routes, and live tracking.
- [OWNER_DOCUMENTATION.md](OWNER_DOCUMENTATION.md): merchant workflows and role-specific management.
- [ADMIN_DOCUMENTATION.md](ADMIN_DOCUMENTATION.md): moderation, users, orders, riders, and statistics.
- [PAYMENT_DOCUMENTATION.md](PAYMENT_DOCUMENTATION.md): current payment metadata and the unimplemented gateway boundary.
